# M5-Mobile 

**M5-Mobile** turns the MStack Tab5 microcontroller tablet into a feature-rich pseudo-smartphone experience. Powered by a custom-built graphics driver, it packs chat integration, utility apps, games, and system tools into low-power hardware.

---

##  Features

* **Custom Graphics Driver:** Built from scratch to handle smooth screen rendering, UI layouts, and fast display updates.
* **Discord App:** Stay connected and chat directly from the microcontroller.
* **Flappy Bird:** On-device arcade mini-game built for quick entertainment.
* **Notes App:** Simple text editor to write and store quick notes locally.
* **Settings App:** Control hardware options, system configurations, and screen behavior.
* **System Info:** Real-time hardware diagnostics, storage monitoring, and RAM/CPU usage.

---

##  Hardware & Tech Stack

* **Hardware:** MStack Tab5 Microcontroller Tablet
* **Graphics:** Custom M5-Mobile Display Engine
* **Environment:** C++ / PlatformIO / Arduino Framework

##  Getting Started

### Prerequisites

* Arduino IDE
* USB-C cable with data transfer support
* The "M5Tab5" Board avalible

### Installation & Flashing

1. **Clone the repository:**
   ```bash
   git clone https://github.com/R3D4CT3D-0/M5-Mobile.git
   cd M5-Mobile
   ```

2. **Open the .ino file inside of the arduino IDE and Ensure that the "M5Tab5" Board is selected**
